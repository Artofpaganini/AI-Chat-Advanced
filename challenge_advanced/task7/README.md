# Task7 — оценка уверенности и контроль качества инференса

Механизм, который решает, можно ли доверять ответу модели, и отказывается отвечать, когда доверять
нельзя. Без дообучения — вся уверенность строится вокруг готовой модели.

**Задача, где ошибка недопустима:** триаж сообщения родителя в приложении ALVA. Свободный текст ->
решение о действии: скорая, врач на днях, обычный ответ, не по теме. Пропустить экстренный случай
недопустимо, лишняя тревога терпима.

**Главный результат:** контроль не делает модель умнее. Он показывает, где ей нельзя верить, и
отказывается отвечать на негодном входе. Единственное, что реально снизило цену безопасности —
проверка **другой** моделью, а не самопроверка.

## Четыре механизма

| Механизм | Где | Что ловит |
|---|---|---|
| Constraint-based | `harness/guards.py` | Сломанный JSON, нарушенный инвариант, негодный вход |
| Redundancy | `harness/pipeline.py` | Неустойчивое решение, 3 сэмпла при t=0.7 |
| Self-check | `harness/pipeline.py` | Упущенный признак, критик с настраиваемым триггером |
| Scoring | `harness/pipeline.py` | Сводит сигналы в `OK` / `UNSURE` / `FAIL` |

Голосование идёт по максимуму тяжести, а не по большинству: одного голоса за `EMERGENCY` достаточно,
чтобы поднять маршрут.

## Быстрый запуск

```bash
cd challenge_advanced/task7

# план вызовов и оценка стоимости, без сети
python3 harness/run_eval.py --dry-run --mode both

# основной прогон, ключ берётся из окружения либо из local.properties
python3 harness/run_eval.py --mode both --workers 6
python3 harness/report.py

# смоук: проверка, что каждый механизм работает
python3 harness/smoke.py
```

Остальные команды, включая три стенда и все эксперименты, — в `REPORT.md` разделе 9.

## Что важно знать

- **Пороги заданы до первого замера** и не подбирались под результат.
- **Ключи только из окружения или `local.properties`**, который в `.gitignore`. В артефакты и логи
  ключ не попадает, проверено при ревью.
- **Отказ отвечать — штатное поведение.** На пустом вводе правильный ответ это `FAIL`, а не
  угаданный маршрут. Отказ по предусловию стоит ноль вызовов.
- **Одиночный прогон не является измерением.** При температуре 0.7 точность гуляет на 8.7 пункта
  между одинаковыми прогонами. Решение принимается по худшему прогону, а не по лучшему.
- **Метрики пересчитаны независимо** при ревью, отдельным скриптом из сырых артефактов — сошлись.
