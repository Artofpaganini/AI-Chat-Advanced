# Спецификация замера

## Контекст

Есть цикл из task4: генерация кода, компиляция, ошибки компилятора обратно модели, правка. Есть шлюз
из task13, который ищет секреты во всём, что уходит модели и приходит от неё. Задача - вставить между
проверками и коммитом шаг проверки безопасности вторым вызовом модели и посмотреть, что он ловит.

## Гипотезы, записанные до прогонов

Не переписываются задним числом. Вердикт - со ссылкой на сырьё.

### H1. Трёх итераций хватит не всегда

**Основание:** в замере task4 ни одна из четырёх моделей не починила свой код по выводу компилятора за
три раунда.

**Вердикт: подтвердилась.** Задача «добавь логирование всех запросов» не сошлась ни разу за пять
прогонов - `raw/loop/loop-20260806.jsonl`, записи с `stopped_at` равным `BUILD` и `GENERATE`.

### H2. Второй вызов модели поймает то, чего не поймал шлюз

**Вердикт: подтвердилась.** Задача 3, второй замер, итерация 1: захардкоженный ключ, вердикт шлюза
`pass`, находка проверки `CRITICAL`. Сырьё - `raw/loop/artifacts/`, ответ проверки задачи 3.

### H3. Более широкая видимость проверки увеличит число находок

**Вердикт: не подтвердилась.** Контролируемое сравнение на одном и том же коде: на хранилище токена
узкая видимость нашла больше, на клиенте запроса - широкая. Эффект разнонаправленный при n=2.

Гипотеза была записана координатором после первого замера в виде утверждения «дешевле всего чинится
состав контекста». Замер её не поддержал.

### H4. Генератор унаследует дефекты проекта

**Вердикт: не подтвердилась, и по неожиданной причине.** В проекте все три локальных адреса по `http`,
генератор написал `https`. Но это не выбор, а следствие изоляции: на вход генерации уходит 400-1100
токенов, ни строки существующего кода там нет.

### H5. Автоматический набор не покрывает стык приложения и сервера

Записана после первого замера, до разбора.

**Вердикт: подтвердилась.** Четыре дефекта самого цикла найдены только чтением артефактов: проверке
отдавался один файл из трёх; сгенерированный код не подключён нигде; задачи затирали файлы друг друга;
записи шлюза не связать с прогоном.

## Метод

**Три задачи из задания дословно.** Каждая провоцирует свой класс небезопасного кода.

**Независимый эталон уязвимостей.** 25 пунктов, автор писал вслепую - без доступа к промпту проверки и
к контракту. Каждый пункт с оценкой «заметит автоматика или нет». Файл заморожен хешем до первого
прогона.

**Третья колонка считается в два прохода.** Механически по эталону - предсказанные пропуски. Руками по
коду - то, о чём не подумал никто. Второй проход дороже и нужнее.

## Ревизия 2026-08-06 - два пункта эталона исключены из зачёта

При починке дефекта в разделе 7.1 контракта координатор пересказал исполнителю промпта два случая из
разбора: зашифрованное хранилище в общем коде и потеря расшифровки после восстановления из резервной
копии. Исполнитель построил на них ловушку и провалидировал промпт.

Это дословно пункты T1-2 и T1-5 эталона. Промпт научен именно им, значит они больше не предсказание.

**Исключены из зачёта до прогона**, не после. Правило про недописывание задним числом работает в обе
стороны: нельзя дописывать эталон после результатов и нельзя после результатов решать, какие пункты
считать честными.

Осталось семь чистых предсказаний из девяти.

## Ревизия 2026-08-06 - слепота нарушена механизмом уведомлений

Контракт правился, пока слепой исполнитель работал, и файл автоматически прилетел ему в контекст.
Эталон уцелел - он был закончен раньше, это проверяется по времени записи.

Урок: во время слепого замера документ, который исполнителю нельзя видеть, трогать нельзя вообще.

## Баги измерителя

Пять, все одного класса - слияние результатов теряет данные молча. Четыре найдены рассуждением до
прогона, пятый - замером:

**Разборщик выбросил ответ проверки, в котором `CRITICAL` уже был найден**, потому что между блоками
не было разделителей. Обошлось случайно - повторная попытка нашла то же самое.

Подробности - `REPORT.md`, раздел 9.

## Ограничения замера

Одна модель, один прогон на задачу, n=2 на контролируемое сравнение. Разброс между попытками виден:
одна находка получала то `HIGH`, то `MEDIUM`.

Ветка слияния находок между попытками проверена только офлайн - случай, ради которого она писалась, в
живых прогонах не встретился.

Работа остановлена на месячном лимите расходов аккаунта: сквозной прогон из чата приложения и задача
про логирование в изменённых условиях не проверены.
