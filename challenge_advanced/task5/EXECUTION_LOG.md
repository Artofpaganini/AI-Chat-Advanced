# Task 5 - Execution Loop. Пул задач и лог выполнения

Проект: JarvisChat (KMP + Compose Multiplatform, чат с AI). Ветка: `task5`.
Профиль прогона: `execution-loop` (base). Оркестратор гоняет пул автономно: задача -> профиль по типу -> сабагент -> сборка -> коммит -> метрика -> следующая.

| | |
|---|---|
| Контекст | `base` (CWD вне `/work`) |
| Исполнитель фич/рефактора | `base-kmp-expert` (shared Compose Multiplatform) |
| Ревьюер | `base-review-expert` |
| Сборка-гейт | `./gradlew :androidApp:assembleDevDebug` + `ktlintCheck detekt` по изменённым |
| Правило паузы | 1 автофикс на задачу; не помогло -> `paused` + причина, идём дальше |
| Метрика времени | wall-clock старт/финиш каждой задачи (мин) |

## Пул задач (15)

Микс: 10 фич, 3 рефакторинг, 1 тесты, 1 доки. Размеры XS-M. Порядок учитывает зависимости (фундамент дизайн-системы -> фичи -> настройки -> микс).

| # | Задача | Тип -> профиль | Размер | Критерий DONE (сделано/не сделано) | Зависит от |
|---|---|---|---|---|---|
| 1 | **AppTheme + light/dark color scheme** | feature | M | Есть `Theme.kt`+`Color.kt`; `lightColorScheme`/`darkColorScheme`; `App.kt` оборачивает в `AppTheme` с `isSystemInDarkTheme()`. Сборка зелёная, приложение реагирует на системную тему | - |
| 2 | **Кастомная Typography** | feature | S | Есть `Type.kt` с `JarvisTypography`, подключён в `AppTheme`. Тексты идут через кастомную типографику, сборка зелёная | 1 |
| 3 | **Токены отступов (Spacing/Dimens)** | refactor | S | Разрозненные `private val Xdp` в UI-файлах заменены единым объектом токенов (`Spacing`/`Dimens`). Поведение не меняется, сборка зелёная | - |
| 4 | **Material-иконки вместо emoji** | refactor | S | Emoji-строки (🔊 ★ 🎤 ⬆︎ ⬇︎) заменены на `Icon` + `material-icons-extended`. Нет emoji-констант в UI, сборка зелёная | 3 |
| 5 | **Копирование сообщения в буфер** | feature | S | Кнопка/действие copy на баббле -> `ClipboardManager`; Snackbar «Скопировано». Сборка зелёная | 4 |
| 6 | **Таймстампы сообщений** | feature | M | `HistoryMessageModel` получает `timestamp` (kotlinx-datetime); время видно под бабблом; старая история без времени грузится без краша. Сборка зелёная | - |
| 7 | **Retry на ошибке ответа** | feature | S | Сообщение-ошибка даёт кнопку «Повторить» -> переотправка последнего запроса. Сборка зелёная | - |
| 8 | **Индикатор «Jarvis печатает…»** | feature | S | Во время загрузки виден typing-баббл вместо/рядом со спиннером. Сборка зелёная | - |
| 9 | **Очистка истории чата** | feature | S | Действие «очистить» в топбаре с подтверждением -> история и файл обнуляются. Сборка зелёная | - |
| 10 | **Пустое состояние (онбординг)** | feature | S | Пустая история показывает приветствие + подсказки вместо пустого списка. Сборка зелёная | - |
| 11 | **FAB «вниз» при прокрутке вверх** | feature | S | Когда список прокручен от низа - виден FAB scroll-to-bottom; тап -> автоскролл вниз. Сборка зелёная | - |
| 12 | **Панель настроек + ручной выбор темы** | feature | M | Overlay/BottomSheet настроек: выбор light/dark/system, сохранение в `multiplatform-settings`/DataStore, переживает рестарт. Сборка зелёная | 1 |
| 13 | **Вынести system-prompt и модель в конфиг** | refactor | S | Захардкоженные `"deepseek-chat"` и system-prompt из `DeepSeekRemoteDataSourceImpl` -> в `AppConfig`/константы модуля. Поведение то же, сборка зелёная | - |
| 14 | **Тесты на новые поля ChatUiMapper** | test | S | `ChatUiMapperTest` покрывает timestamp (#6) и typing (#8); тесты зелёные (`:feature:chat` host-test) | 6, 8 |
| 15 | **README модуля feature/chat** | docs | XS | `feature/chat/README.md`: что умеет, Action/State/Event, use-cases, точки расширения. Осмысленный, актуальный | - |
