# Task 4 - локальная LLM как код-ассистент в IDE

Локальная модель подключена в Android Studio как чат + автокомплит + агент, настроена под этот проект
и прогнана по тем же задачам, что и облачный ассистент в Днях 1-2.

## Что где лежит

| Путь | Что это |
|---|---|
| **`USAGE.md`** | **как пользоваться: включить, работать, выключить, починить** |
| `PLAN.md` | план и метод прогона, чек-лист шагов |
| `BENCHMARK.md` | все замеры: скорость, контекст, параметры, автокомплит |
| `TASKS.md` | задачи A (генерация фичи) и B (агентный режим): что просили, что вышло |
| `COMPARISON.md` | таблица «облако против локали» + рекомендация «для чего хватает локальной» |
| `FINAL_REPORT.md` | сводка на одну страницу |
| `harness/` | обвязка замеров, воспроизводит все числа |
| `raw/` | сырые ответы API и логи прогонов |
| `results/` | машинные результаты замеров в json |
| `artifacts/config/` | снапшот финальных конфигов |
| `artifacts/generated/` | код, сгенерированный каждой моделью в задаче A |

Живые конфиги (не снапшоты) лежат вне этой папки:

| Путь | Что это |
|---|---|
| `~/.continue/config.yaml` | модели, роли, параметры генерации |
| `<проект>/.continue/rules/01-kotlin-conventions.md` | файл правил Дня 1 в системном промпте, применяется всегда |
| `<проект>/.continue/rules/02-compose-ui.md` | правила UI, применяются только к `presentation/**` |
| `<проект>/.continueignore` | что модель не должна видеть |

## Как воспроизвести

```bash
ollama serve &                       # рантайм
cd challenge_advanced/task4/harness
python3 bench_speed.py               # скорость, TTFT, контекст, память
python3 params_sweep.py              # temperature / top_p
python3 bench_fim.py                 # автокомплит на реальных дырках проекта
python3 run_taskA.py                 # задача A на всех чат-моделях
python3 compile_taskA.py <sandbox>   # компиляция сгенерированного кода
python3 agent_loop.py <model> <sandbox>   # задача B, агентный режим
```

`<sandbox>` - клон этого репозитория (`git clone --local`). Рабочее дерево при замерах не меняется.

## Живая проверка в IDE (одна минута руками)

Скриптом не сделать: macOS не даёт `osascript` отправлять нажатия клавиш в Android Studio без
разрешения в Системных настройках. Поэтому так:

```bash
python3 harness/proxy_log.py &     # прокси на :11435, пишет raw/ide_traffic.jsonl
sed -i '' 's|11434|11435|g' ~/.continue/config.yaml
```

Дальше в Android Studio:

1. Открыть любой Kotlin-файл проекта, дописать полстроки и подождать секунду - это дёрнет автокомплит.
2. Открыть панель Continue, спросить что угодно про открытый файл - это дёрнет чат.

После этого:

```bash
python3 -c "import json;[print(json.loads(l)['path'], json.loads(l).get('model'), json.loads(l).get('prompt_chars') or json.loads(l).get('message_chars')) for l in open('raw/ide_traffic.jsonl')]"
sed -i '' 's|11435|11434|g' ~/.continue/config.yaml   # вернуть напрямую
```

В логе будет видно: какая модель дёрнулась, какие параметры ушли, был ли это FIM-запрос
(поле `fim: true` - автокомплит) или диалог (`messages > 0` - чат), и сколько токенов контекста
плагин реально отправил.
