Задача: в фиче чата уже есть экспорт истории в JSON. Добавь рядом экспорт в Markdown.

Требования:
1. Найди в коде, как устроен экспорт в JSON: use-case, репозиторий, data source, action в UI.
2. Сделай экспорт в Markdown по той же схеме, не ломая существующий JSON-экспорт.
   Формат файла: заголовок `# Chat history`, дальше по строке на сообщение
   `- **<автор>**: <текст>`, избранные помечаются `⭐`.
3. Добавь `Ui`-action на экспорт в Markdown и обработку в ViewModel, включая ветку ошибки.
4. Соблюдай конвенции проекта: нейминг слоёв, `internal`, `updateState { copy(...) }`, никаких `Dto`, `!!`, `Any`,
   именованные параметры лямбд, никаких комментариев.
5. Когда закончил править файлы - собери проект инструментом `build` и почини ошибки, если они есть.

Работай инструментами: сначала осмотрись (`list_dir`, `search`, `read_file`), потом правь (`write_file`), потом собирай (`build`).
Не выдумывай пути - проверяй их чтением. Когда всё собрано, ответь коротким текстом со списком изменённых файлов.
