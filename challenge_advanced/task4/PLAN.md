## 1. Связка

**Ollama + Continue (плагин для JetBrains).** Единственная связка, которая в Android Studio даёт чат,
автокомплит и агентный режим сразу и настраивается файлом, а не кликами.
LM Studio отпадает: GUI хороший, но в JetBrains он не даёт автокомплит внутри редактора.

## 2. Метод замера (главное отличие этого прогона)

Ошибки, которых сознательно избегаем:

1. **Замер под нагрузкой.** Перед каждой моделью делается `unload`, между кейсами - прогрев.
   Числа берутся из полей ответа ollama (`eval_count`, `eval_duration`, `load_duration`,
   `prompt_eval_*`), а не секундомером снаружи - иначе в цифры попадает наш собственный оверхед.
2. **Модель отсеяна без замера.** Каждая модель из ростера проходит полный круг: скорость, контекст,
   задача A, задача B. Отсев только по измеренным числам.
3. **Сырые данные в /tmp.** Все ответы API складываются в `raw/` внутри репозитория.
4. **Оценка кода на глаз.** Конвенции проверяются скриптом (`codegen_lib.py`): запрещённые конструкции,
   обязательные конструкции, раскладка по каталогам. Плюс реальная компиляция.
5. **Компиляция в рабочем репозитории.** Сгенерированный код собирается в клоне проекта
   (`bench-repo`), рабочее дерево не трогается.
